# 1hSona-Image-Sharing

Interactive **Sona × 1Health** demo (image sharing → provider network) built as a single React module plus a minimal Vite shell.

**Primary demo:** `sona-1health-demo2.jsx` — multi-step flow with **New physician** vs **Existing physician**, 1Health-style chrome (teal/blue), registration, embedded dashboard, and a network-effect closing screen.

**Earlier prototype:** `sona-1health-demo.jsx` — longer single-file walkthrough (still in the repo for reference).

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (default **http://localhost:5173**).

```bash
npm run build   # production bundle
npm run start   # preview built `dist/` (run build first)
```
